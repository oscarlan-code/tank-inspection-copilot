# Tank Inspection Copilot — Business Development Deck V3

## Positioning

Tank Inspection Copilot is a structured inspection workflow for aboveground storage tank inspections.

The commercial idea is:

- capture inspection data once in the field
- turn it into a canonical inspection record
- use an intelligence layer to organise that record into a report-ready output package

This version of the deck focuses on:

- current workflow pain
- the data-first concept
- structured capture by task
- output package value
- AI-assisted one-click report generation

## Slide 2 — Current Inspection Workflow

**Title:** Current inspection workflow

Workflow:
1. Field inspection
2. Separate records
3. Back-office re-keying
4. Rebuild context
5. Merge MFL separately
6. Final QA and report

Pain points to highlight:

- duplicate entry
- broken links between UT, findings, and photos
- weak location traceability
- fragmented outputs

Core message:

> Today, the inspection and the report are still two different workflows.

**Title:** In-context finding capture

Flow:
1. Photo
2. Annotate
3. Type and severity
4. Location
5. Measurements
6. Save

Core message:

> Findings are documented inside the active task, not reconstructed later from memory.

---

## Slide 7 — Location Intelligence by Surface

**Title:** Location intelligence by surface

Surface logic:

- Shell: coarse UT + optional precise shell mapping
- Roof: ring / section / plate-based coarse layout
- Shell nozzles: course + degree on unwrapped shell
- Roof nozzles: roof map registration before readings

Core message:

> The app uses the right level of mapping for each surface instead of forcing one location model everywhere.
