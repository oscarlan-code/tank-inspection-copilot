# Mock Preparation sandbox

This directory contains editable agent candidates. Candidate code is reviewable and
may be committed; generated requests, model responses, Android staging data, and
run outputs belong in private `.local` case folders and remain ignored by Git.

Current candidate:

- `candidates/mock-preparation-v1`: complete-report mock preparation candidate using
  `gpt-5.6-sol` for the two controlled narrative variations.

A sandbox candidate cannot be called a release or used by product routing. Move it
through the documented qualification and promotion gate first.
