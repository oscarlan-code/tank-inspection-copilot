# Contents Classification Agent v2 candidate

Status: evaluation candidate with bounded runtime; no product route.

This candidate consumes the frozen `vertical-api653-v1` outline vocabulary and keeps
five stages separate: authenticated Android input, deterministic atomization,
closed-book primary-route classification, fail-closed guarding, and isolated section
packages. The independent evaluator remains outside the runtime candidate.

Voice atoms receive zero or one primary route. Multi-use remains available only through
separate atoms or deterministic cross-references. Actual ProductStore exports and native
source pointers remain unchanged.

Every evaluation records one fingerprint across the runtime, prompt, guard, outline,
atomizer, leakage policy, and candidate configuration. A robustness cohort must use a
different case, document, source hash, and asset lineage from all development cases.
Gold and lineage metadata remain evaluator-private and are audited out of every worker
request. Results from a training-corpus report may be called an independent robustness
check, but never held-out validation.
