# Documentation archive

This directory preserves superseded designs, research notes, and session markers for
provenance. Archived documents are read-only historical records. They do not define
current runtime behavior and must not be copied into new code without revalidation
against the active root contracts.

- `architecture/`: superseded whole-system and implementation plans.
- `report-generation/`: detailed designs consolidated into the lean active pipeline.
- `research/`: source-specific studies and formatting observations.
- `session-markers/`: old continuation notes.

Dated qualification evidence remains under `../reviews/` because it records test
results rather than architecture authority.
