# TK-465 Sample Report Structure

Source:

- `16TJS4 -1 TK 465 Internal & External Inspection Report.pdf`

Use this file as a format guard rail for report drafting.

## Verified section order

1. Scope of Inspection
2. Inspection and Maintenance Regime
3. General Tank Information
4. Inspection Report
5. Repair Recommendations / API 653 Assessment
6. Test Information
7. Tank Inspection Checklist
8. Roof Plate Thickness Measurements
9. Roof Plate Layout
10. Roof Nozzle & Reinforcement Pad Thickness Measurements
11. Minimum Shell Thickness Calculations
12. Shell Plate Thickness Measurements
13. Shell Plate Layout
14. Shell Nozzle & Reinforcement Pad Thickness Measurements
15. Photographs
16. Floor Plate Layout with Platemaps Numbering System
17. Floor Recommended Repair Locations
18. Guidelines for the Interpretation of the TRU-FLUX Data Sheets
19. Floor Plate Corrosion Plan
20. Magnetic Flux Leakage Platemaps

## Format behavior

- The report is section-led, not chat-led.
- Scope appears before narrative and recommendations.
- Measurement sections and layout sections are separated.
- Checklist is a full section, not an inline note.
- Floor and MFL content occupy the final block of sections.

## Section shape cues

- `Scope of Inspection` is a job-scope list, not a narrative summary.
- `Inspection and Maintenance Regime` reads as a short regime/policy block.
- `General Tank Information` behaves like a factual information section.
- `Inspection Report` is the main narrative findings section.
- Layout sections behave like figure pages with captions and support notes.
- Blocked floor or MFL sections should remain visibly deferred rather than being improvised.

## Tone behavior

- Use formal inspection-report wording.
- Avoid chatty explanation.
- Present measurements and observations before recommendations.
- Keep unsupported sections visible rather than silently dropping them.
